Conectar este celular

É a mesma chave do GitHub que você usa para trocar o prêmio do Desafio. Se este celular já está conectado lá, esta tela nem aparece.

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Nome: adm gabba. Expiration: 366 days ou No expiration.
  3. Repository access: Only select repositories → -roleta-gabba.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copie (começa com github_pat_) e cole aqui.

A chave fica guardada só neste celular. Não mande para ninguém.
