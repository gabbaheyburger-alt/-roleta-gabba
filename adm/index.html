Conectar este celular

Para salvar o prêmio, este celular precisa de uma chave do GitHub que só pode mexer na pasta dos jogos. É feito uma única vez.

  1. Abra github.com/settings/personal-access-tokens/new no navegador (entre na sua conta se pedir).
  2. Em Token name, escreva adm desafio. Em Expiration, escolha 366 days ou No expiration.
  3. Em Repository access, marque Only select repositories e escolha -roleta-gabba.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Toque em Generate token, copie a chave (começa com github_pat_) e cole aqui.

A chave fica guardada só neste celular. Não mande para ninguém. Se perder o celular, apague a chave em github.com/settings/personal-access-tokens.
